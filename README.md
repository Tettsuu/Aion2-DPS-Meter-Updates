# AION 2 DPS Meter Lunar

Creado por Ambulancia/Tettsuu.

Este es el canal de descargas y actualizaciones de la edición V2. El repositorio de trabajo continúa privado.

Descarga los paquetes publicados desde [Releases](https://github.com/Tettsuu/Aion2-DPS-Meter-Updates/releases). Extrae el ZIP del programa en una carpeta propia. Para sustituir una instalación anterior, cierra el medidor y conserva `Datos-V2`, `historial.json` y `dungeon-global.json`.

Las actualizaciones se consultan en Ajustes → Update. Antes de instalar se pregunta Sí / No. La instalación espera al final del combate y vuelve a abrir el medidor conservando los datos.

El archivo `Codigo-Fuente` de cada versión contiene el código correspondiente y las licencias GPL y de terceros. Los paquetes no incluyen configuraciones ni historiales personales.
